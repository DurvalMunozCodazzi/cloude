Configuración de Email (SMTP)

Usá una Contraseña de Aplicación de Google: Google Account → Seguridad → Verificación en 2 pasos → Contraseñas de aplicaciones → Crear una nueva (nombre: "Reserva Total").

WhatsApp automático (opcional)

Los botones de WhatsApp de cada reserva funcionan siempre (abren WhatsApp con el mensaje armado). Si además querés que los recordatorios de check-in salgan solos, cargá acá las credenciales de la API de WhatsApp Business de Meta (Meta for Developers → tu app → WhatsApp → API Setup).

💳 Mercado Pago — reserva online

Con esto activado, los huéspedes reservan y pagan la seña solos desde tu página de reserva online (el link está en 📅 Disponibilidad y Sync → Enlaces). El Access Token se saca de mercadopago.com.ar → Tus integraciones → Credenciales de producción.
